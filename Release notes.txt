These are builds of an interim AutoWikiBrowser release, currently identified as 6.5.0.1. They are based on SVN revision 13045.

Download:
AutoWikiBrowser6500.zip, equivalent to the official release.
AutoWikiBrowser6500-arm64.zip, preferred for an ARM64 device, but also (despite the name) intended for an x64 device when a large address space is needed.

Significant update: The Database scanner offers the user the ability to scan every XML file in the same directory, because Mediawiki dumps are now split into smaller files.
